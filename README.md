# Ilustrador

Skill do Claude para gerar desenhos e ilustrações.

Analisa o contexto do projeto, escolhe entre Gemini e ChatGPT, usa o outro se o limite acabar, depois o Canva e, por último, desenha em SVG. O Canva também faz o acabamento (texto, logo e formatos). Nada é aplicado sem aprovação.

## Instalação

Copie o `SKILL.md` para `~/.claude/skills/ilustrador/`.

## Requisitos

- Claude in Chrome, com login no Gemini e no ChatGPT
- Conector do Canva (reserva e acabamento)
